# 🩺 Breast Cancer Prediction Using XGBoost

A machine learning project that predicts whether a breast tumor is **Benign** or **Malignant** using an **XGBoost Classifier**. The trained model is deployed through an interactive **Streamlit** web application.

## 📌 Project Overview

The goal of this project is to build an end-to-end machine learning classification system for breast cancer prediction using tumor measurements from the **Breast Cancer Wisconsin Dataset**.

The application accepts tumor feature values from the user and predicts one of two classes:

- 🟢 **Benign**
- 🔴 **Malignant**

## 🤖 Machine Learning Model

The deployed classification model is **XGBoost (Extreme Gradient Boosting)**.

The application uses three saved objects:

- `model.pkl` — trained XGBoost model
- `scaler.pkl` — fitted feature scaler
- `features.pkl` — saved feature names and their required order

Before prediction, the application arranges the entered values in the same feature order used during training and applies the saved scaler.

## 📊 Dataset

**Dataset:** Breast Cancer Wisconsin Dataset

The dataset contains numerical measurements describing breast tumor characteristics. These features are used to train the model to distinguish between benign and malignant tumors.

## 💻 Streamlit Application

The Streamlit application provides a simple interface for entering tumor measurements and obtaining a prediction.

### Prediction Process

1. Load the trained XGBoost model.
2. Load the saved scaler.
3. Load the saved feature names.
4. Generate input fields for all required features.
5. Convert the entered values into a Pandas DataFrame.
6. Arrange the columns in the same order used during training.
7. Scale the input using the saved scaler.
8. Pass the processed data to the XGBoost model.
9. Display the prediction as **Benign** or **Malignant**.

